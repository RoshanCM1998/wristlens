# WristLens

See your phone camera's live picture on an Amazfit / Zepp OS watch, and take the photo from your wrist. Works with the camera app already on your Android phone.

**Website:** https://roshancm1998.github.io/wristlens/

**Download the phone app:** [WristLens.apk (latest)](https://github.com/RoshanCM1998/wristlens/releases/latest/download/WristLens.apk)

Free beta with a free trial. Questions or problems: wristlens.app@gmail.com — the app's **Send feedback** button fills in the details for you.

This repository holds the website and app downloads; the source code is private.
